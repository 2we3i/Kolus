# 🚀 KAST Tools — Kolus & Vipum

Набор пользовательских скриптов для автоматизации заполнения форм (опоры, пересечения, дополнительная нагрузка и т.д.).

Разработано командой **KAST Team** 💜

---

## 📦 Состав проекта

### 1️⃣ Kolus

UI-модуль для управления заполнением пересечений и параметров крепления.

**Возможности:**

* 🔀 Автозаполнение пересечений
* 🌳 Выбор объекта пересечения (например, дерево и др.)
* ⚙️ Управление типами крепления
* 🔔 Глобальные уведомления
* 👁️ Скрытие / показ интерфейса
* ⌨️ Горячая клавиша: `ALT + З`

Версия в коде: `v1.6.3
`

---

### 2️⃣ Столб

UI-панель для заполнения формы опоры (столба).

**Возможности:**

* 🏗️ Выбор марки опоры
* 🧱 Автоопределение материала по типу
* 📐 Выбор конструктивного типа
* 📍 Указание местоположения
* 🔧 Настройка укосов (количество + материал)
* ⚡ Дополнительная нагрузка:

  * 🗄️ Шкаф
  * 📡 Линия связи
  * 💡 Фонарь
  * 🔌 Муфта ВОЛС
* 📋 Встроенный журнал логов

  * Копирование логов
  * Очистка логов
* 📷 Автоматический переход к добавлению фото
* 🪵 Поддержка приставок (для деревянных опор)
* ✨ Кнопка «Заполнить форму»

Версия в коде: `v1.8.4 DEBUG`

---

## 🧠 Логика работы

Скрипты:

* Отслеживают появление формы
* Автоматически подставляют значения
* Управляют счётчиками (стойки, укосы, приставки)
* Заполняют поля через DOM
* Работают с React-select
* Поддерживают автосинхронизацию нагрузки

## 🔧 Установка

### Способ 1 — Tampermonkey (рекомендуется)

1. Установить расширение:

   * Chrome — Tampermonkey
   * Edge — Tampermonkey
   * Firefox — Tampermonkey

2. Создать новый пользовательский скрипт

3. Вставить код `Kolus.txt` или `Vipum.txt`

4. Сохранить

5. Обновить страницу с формой

---

## 🗂 Структура

```
/Kolus.txt      — модуль пересечений
/Vipum.txt      — модуль заполнения опоры
```

---

## 📊 Основные функции

* `fillField()` — заполнение input
* `setCounter()` — установка количества элементов
* `clickReactSelect()` — работа с select
* `clickCamera()` — переход к фото
* `showGlobalNotification()` — уведомления
* `toggleUI()` — управление видимостью

---

## 🛡 Особенности

* Не ломает оригинальную форму
* Работает поверх интерфейса
* Поддерживает динамические поля
* Поддерживает разные типы опор
* Автоматически учитывает материал
